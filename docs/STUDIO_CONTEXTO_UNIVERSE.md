# Contexto de Studio y Universe

Base auditada: PR #40, `918f5a6`. La suite de referencia reportó
474 aprobadas y 6 omitidas. Se reutilizan el arrastre de TkDND,
los visores, los permisos, los motores del Profesor y los adaptadores
CAZEL/DARAS, sin editar repositorios externos.

- El inspector nativo y web muestra tipo, origen y fecha local. Para
  recuerdos expuestos como nodos de memoria, el POST autenticado
  exige READ, WRITE y confirmación. Los nodos de modelos y lecciones
  conservan sus propias reglas de gestión. Las fechas ausentes se
  identifican como «Sin registrar».
- La modalidad se decide antes de iniciar cámara. El marcador no
  depende del detector de manos. La activación conserva el diálogo de
  permiso y la pausa.
- Las peticiones ambiguas de electrónica reciben opciones de
  herramientas sin ejecución automática. La detección de algunas
  faltas se hace de forma explícita y limitada.
- La actividad GitHub consulta diez resultados públicos de la API
  oficial. La publicación desde Cerebro queda fuera de esta entrega.

Se comprobó en Chromium el inspector y el borrado, además del visor
PDF y la generación con doble de modelo. Studio nativo en Xvfb verificó
el visor, el relevo de ventanas y la ruta de carpeta al invocar el
callback de TkDND con una URI real. Se consultó la API real de GitHub
para diez commits públicos.

Quedan pendientes Google OAuth, autorización persistente de carpetas,
reorganización completa de pestañas, gestos en hardware físico
incluido cambiar pestañas, captura visual y entrenamiento medible
con modelos generativos y especialistas reales.
