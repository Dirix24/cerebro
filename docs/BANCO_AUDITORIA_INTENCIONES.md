# Banco reservado de auditoría

Etiquetas manuales por familia. Estas frases no se usan para entrenar ni para ampliar el validador. Una orden ambigua, negada o compuesta requiere abstención del clasificador de acción única. El alumno publicado solo se evalúa para hora y fecha; en las otras familias se comprueba que no reclame la orden.

| Familia | Frases |
| --- | --- |
| Hora | ¿Podrías indicarme la hora exacta? · Por favor dime qué hora es · Dme la ora local |
| Fecha | ¿Cuál es la fecha en este equipo? · Qué fechaa es · Necesito la fecha de ahora |
| Búsqueda local | Encuentra el presupuesto que guardé · Dónde está mi fichero de gastos |
| Apertura | Abre ahora el PDF seleccionado · Ponme en pantalla el archivo que encontraste |
| Búsqueda web | Investiga en la web el clima marciano · Busca en internet información de Saturno |
| Estado | ¿Cuánta memoria queda en el equipo? · Dame el estado actual del sistema |
| Ambigüedad | Ponme eso · Busca el PDF y luego ábrelo |
| Negación | No me muestres la hora actual · No abras el archivo |
| Fuera de distribución | Qué hora era ayer en Madrid · Escribe qué hora es como título |
